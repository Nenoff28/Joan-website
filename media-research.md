# Joan Media Source Notes

The original Joan About page uses the store photograph at `https://joan.bg/image/catalog/joan-about.jpg`. This is the user-requested source image for the redesigned About section.

The direct redesign-style path `https://joan.bg/category/instrumenti` is not a valid route on the original storefront. Real product imagery will therefore be gathered from the original site’s search, promotion, and product-page routes rather than assumed category slugs.

The original promotions page exposes real product-card photography at `https://joan.bg/special`, including pool, building-material, boiler, drill, and paint product images. The page’s image URLs are served from the Joan `image/cache/catalog/` path and can support representative photography across the test catalogue.
