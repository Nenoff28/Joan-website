# Joan Administration: Professional Operations Upgrade

## Dashboard and Daily Control

The Overview becomes the daily operating console. It will surface a **catalogue health scorecard**, active promotions, stock exceptions, request workflow counts, and the latest administrator actions. Every metric links to the affected work queue rather than acting as decorative reporting.

## Inventory and Catalogue Quality

The product workspace gains a dedicated inventory lens, quick quantity adjustments, stock-health filtering, and attention queues for inconsistent availability, missing pricing, missing SKU codes, single-image galleries, and unpublished records. Inventory updates are logged with the responsible administrator and are immediately reflected in the public catalogue state.

## Promotion Control

The promotion workspace lists current discounted records and provides a fast edit surface for selling price, previous price, Bulgarian price, and promotion label. It also identifies price records needing completion before a promotion can be published. Promotions remain product-level, with no fabricated discount data introduced by the system.

## Request Workflow

The orders workspace becomes a request-control board. Operators can filter by status, review priority counts, write internal notes, and move records through **new**, **contacted**, **confirmed**, **closed**, and **cancelled** states. These are order requests only; no payment information is stored or processed.

## Audit and Accountability

An Activity view exposes recent, material administrator actions: catalogue changes, category changes, image uploads, inventory updates, promotion changes, and request-status changes. Each record includes the administrator identity, timestamp, entity, and concise activity metadata.

## Acceptance Criteria

| Area | Completion condition |
|---|---|
| Dashboard | Shows live metrics, attention queues, and recent operational activity. |
| Inventory | Supports logged, bounded quantity adjustments and exception filtering. |
| Promotions | Supports live product-level promotion management without fabricated values. |
| Requests | Supports status filtering and internal-note maintenance. |
| Audit | Shows genuine administrator events from persisted activity records. |
| Quality | Highlights actionable gaps using real record fields only. |
| Responsive design | Daily control workflows remain usable on mobile and desktop. |
